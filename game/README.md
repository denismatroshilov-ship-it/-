# Точка реза

Аркада под iPhone 12 про то же, чем занят бот из корня репозитория: поймать
момент склейки с точностью до кадра, пока зритель не свайпнул.

Игла идёт по линейке времени. Бирюзовая зона — сильный момент, тап внутри неё
и есть рез: чем ближе к центру, тем выше просмотры. Красная зона — вода, по ней
резать нельзя. Удержание всё время течёт вниз, и добирается оно только точными
резами; упало до нуля — ролик умер.

Ни одного мегабайта ассетов: кадр на мониторе, зерно плёнки, звук и иконки
рисуются кодом. Поэтому игра целиком работает без сети.

## Как запустить на телефоне

Сложить на экран «Домой» — тогда она открывается как приложение, без адресной
строки и без интернета:

1. открыть страницу игры в Safari;
2. Поделиться → «На экран „Домой“».

Локально, если хочется погонять с компьютера:

```bash
cd game && python3 -m http.server 8000
# на телефоне в той же сети: http://<ip-компьютера>:8000
```

Service worker включается только по http(s) — с `file://` игра тоже работает,
но без оффлайн-кэша.

## Что где лежит

| Файл | Что внутри |
| --- | --- |
| `game.js` | вся игра: сложность, счёт, отрисовка монитора и линейки, звук |
| `game.css` | оформление: тёмная монтажка, костяной текст, коралловый рез |
| `index.html` | обвязка под PWA: мета-теги iOS, манифест, регистрация SW |
| `sw.js` | оффлайн-кэш: своё — из кэша, шрифты — из сети с запасом |
| `icon-*.png` | иконки для экрана «Домой», сгенерированы кодом |

Цифры сложности собраны в начале `game.js`, рядом с ценой промаха и ценой
идеального реза — менять баланс нужно там, а не по коду:

```js
const GAIN    = { perfect: 11, good: 7, ok: 4 };      // сколько удержания вернёт рез
const PENALTY = { miss: 15, decoy: 22, timeout: 17 }; // сколько снимет промах
const VIEWS   = { perfect: 24000, good: 9000, ok: 3200 };
```

## Как растёт сложность

| Дубль | Что меняется |
| --- | --- |
| 1 | одна зона, проход 2,3 с |
| 4 | появляется вода — красная зона |
| 8 | две зоны за один проход |
| 10 | две зоны воды |
| 12 | зона плывёт по линейке |
| 16 | игла возвращается: второй проход по тому же материалу |

Проход ускоряется до 0,85 с, зона сужается до ~3 кадров из 120 — дальше решает
только точность.
