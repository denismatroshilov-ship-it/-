# Hermes — iOS-приложение для управления ботом

Нативное приложение под iPhone (SwiftUI). Через него с телефона видно очередь
роликов, можно аппрувить, публиковать «Сейчас» или «В слот», менять подпись и
генерировать сценарии-хуки — те же операции, что у Telegram-бота, но своим
интерфейсом.

Приложение — только клиент. Вся логика (нарезка, публикация в TikTok) остаётся
на сервере: приложение ходит по HTTP к API бота (`app/api.py`).

## Что нужно на сервере

В `.env` того же проекта включить API и задать токен:

```
HERMES_API_TOKEN=<длинный случайный токен>   # python -c "import secrets; print(secrets.token_urlsafe(32))"
HERMES_API_PORT=8000
```

Запустить бота как обычно — `python -m app.main`. В логах появится строка
`API для айфона слушает 0.0.0.0:8000`. Узнай IP машины в локальной сети
(`ipconfig getifaddr en0` на macOS, `hostname -I` на Linux) — это и будет адрес
`http://<ip>:8000`.

## Как запустить на айфоне (без App Store)

Нужен Mac с Xcode — собрать и поставить приложение можно бесплатно, по личному
Apple ID (сборка живёт на телефоне 7 дней, потом переустановить).

1. Открой `ios/Hermes/Hermes.xcodeproj` в Xcode.
2. Target **Hermes** → вкладка **Signing & Capabilities** → выбери свою команду
   (Personal Team по Apple ID). При желании поменяй Bundle Identifier
   (`com.hermes.studio`) на свой уникальный.
3. Подключи iPhone кабелем, выбери его в списке устройств вверху.
4. Нажми ▶︎ (Run). Первый раз на телефоне: **Настройки → Основные → VPN и
   управление устройством** → доверься своему профилю разработчика.
5. В приложении открой вкладку **Настройки**, впиши адрес `http://<ip>:8000` и
   тот же токен, что в `.env`. Кнопка «Проверить связь» должна дать ✅.

Телефон и сервер должны быть в одной сети. Если хочешь управлять извне —
выставь сервер наружу по HTTPS (обратный прокси) и укажи https-адрес; тогда
можно ужесточить `NSAppTransportSecurity` в `Info.plist`.

## Экраны

- **Очередь** — ролики в статусе `awaiting_approval`. Кнопки «🚀 Сейчас», «⏰ В
  слот», меню «изменить подпись / отклонить». Сверху — сводка по статусам.
- **Сценарии** — вводишь сцену, получаешь 5 вариантов хуков с раскадровкой и
  готовой подписью (тот же `/hooks`).
- **Настройки** — адрес сервера, токен, проверка связи, список подключённых
  TikTok-аккаунтов.
