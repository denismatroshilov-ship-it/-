# series/ — производственная линия Mind & Money

Отдельная от TikTok-нарезки ветка работы: `app/` режет чужие фильмы и по
своему принципу видео не генерирует, здесь свой сериал. Общего кода нет.

Канон сериала, снятый с вышедших серий, — `CANON.md`. Читать первым.

## Четвёртая серия

| Файл | Что внутри |
| --- | --- |
| `ep04/episode.py` | Источник: 34 сцены, у каждой закадровый текст и промпт кадра |
| `ep04/PROMPTS.md` | Те же промпты по одному, самодостаточные, с именем файла для каждого кадра |
| `ep04/VOICEOVER.md` | Только закадровый текст, пронумерованный |
| `ep04/description.txt` | Описание для YouTube: хук, список, исследования, дисклеймер, главы |
| `ep04/manifest.json` | Тайминг и метаданные, по ним идёт сборка |

## Как довести серию до готовой

1. **Кадры.** Взять промпт из `PROMPTS.md`, сгенерировать любым доступным
   инструментом, сохранить в `ep04/build/frames/` **под именем плана**
   (`mm_ep04_07_looking_only_adds_feeling.png`). Кадры можно докладывать по
   одному: планы без кадра остаются заглушками и сборку не ломают.
2. **Озвучка.** Реплики из `VOICEOVER.md` голосом сериала, файлы в
   `ep04/build/audio/` под теми же именами планов. Тайминг пересчитается по
   реальной длине реплик, субтитры отключатся сами.
3. **Сборка.**

```bash
python3 series/assemble.py series/ep04/manifest.json
```

Сборщик берёт по каждому плану лучшее, что есть: клип → кадр с медленным
наездом → заглушка. Звук нормализует до −14 LUFS. Нужны `ffmpeg` и
`rsvg-convert`.

## Свои материалы

Если серия делалась где-то ещё, она заводится с готового:

```bash
python3 series/ingest.py --episode 5 --frames ~/mm/ep05 --vo ~/mm/ep05/vo.txt
```

Число планов задаёт файл реплик, а не папка с картинками.

## Про доступы

На момент написания генерация кадров из этой сессии недоступна: у Higgsfield
нулевой баланс, у коннектора ElevenLabs выключено разрешение Image & Video
Generation (403), и там же дневной лимит бесплатного плана. Поэтому промпты
написаны так, чтобы работать в любом стороннем генераторе, а сборка не
зависит от того, чем именно сделаны кадры.
