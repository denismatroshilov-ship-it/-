# series/ — производственная линия сериала

Отдельная от TikTok-нарезки ветка работы. Приложение в `app/` режет чужие
фильмы и по своему принципу видео не генерирует; здесь наоборот — свой
сериал, кадры которого генерируются. Общего кода у них нет, `app/` эта
папка не трогает.

## Канон сериала

Ультра-фотореалистичная комедия про секретных агентов в духе конца 1990-х.
Ночной Манхэттен 1998 года, 16:9, 24 fps, натурная натриевая подсветка,
мокрый асфальт, текстура 35-мм плёнки. Тон — сухой deadpan, не слэпстик.

Серия = один непрерывный 12-секундный эпизод из шести двухсекундных планов
с жёсткими склейками. Так сделаны первая и вторая серии, так делается
четвёртая.

### Персонажи

| Кто | Описание |
| --- | --- |
| Главный агент | Лицо — по референсу (`assets.face_reference` в манифесте). Очень коротко стриженный, борода, чёрный костюм в две пуговицы, белая рубашка, узкий чёрный галстук, узкие прямоугольные чёрные очки. Спокоен всегда. |
| Второй агент | Безымянный, та же униформа, эмоции живее. |
| Краб-инопланетянин | Размером с кошку, мокрый хитин, шесть ног, глаза на стебельках. Смешной, но правдоподобный. |
| Три свидетеля | Гражданские, у одного одноразовая плёночная мыльница. |

Реквизит: чёрный седан без опознавательных знаков, серебристый прибор
стирания памяти, светящаяся инопланетная слизь в переулке, таксофон,
жёлтое такси, пожарные лестницы.

## Сборка

```bash
python3 series/assemble.py series/ep04/manifest.json
```

Скрипт собирает финальный mp4 из того, что реально лежит в `build/`:
готовые клипы — монтаж встык, только кадры — аниматик с выдержкой по
таймингу плана, ничего нет — цветные слейты с номерами планов. То есть
смотрибельный результат получается на любой стадии, и та же команда даёт
финальную серию, когда кадры сгенерированы.
