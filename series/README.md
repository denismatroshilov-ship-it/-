# series/ — производственная линия Mind & Money

Отдельная от TikTok-нарезки ветка работы. Приложение в `app/` режет чужие
фильмы и по своему принципу видео не генерирует; здесь свой сериал —
объяснялки про психологию денег со стикманом. Общего кода у них нет,
`app/` эта папка не трогает.

## Канон

Формат — минималистичная дудл-анимация: кремовый фон, толстый чёрный
контур, фигура-стикман с круглой головой, точками-глазами и маленькой
дугой рта. Один кадр — одна метафора: фигура слева, предмет справа, между
ними линия земли. 16:9, 24 fps.

Палитра снята пипеткой с кадра предыдущей серии, который лежит в
воркспейсе ElevenLabs (`style_reference.asset_id` в манифесте), а не
подобрана на глаз:

| Роль | Цвет |
| --- | --- |
| Фон | `#FBF7F1` |
| Контур | `#272724` |
| Тил | `#51867E` |
| Охра | `#D9A84C` |
| Тёмно-серый (техника) | `#424242` |

Голос — «альберт» (`7O2znNqD2IdXSYSrr6sb`) из того же воркспейса,
спроектированный под этот формат: спокойный, английский акцент, с
интонацией. Он же прописан в манифесте, чтобы серии звучали одинаково.

## Как устроено производство

Кадры не генерируются моделью, а собираются кодом из примитивов
`style.py` — голова, корпус, рука-трубка, машина, монета, телефон. Поэтому
стиль не плывёт между планами и между сериями, а любой кадр
пересобирается заново одной командой. Изменить толщину контура или
пропорции фигуры можно в одном месте, и это подхватят все серии.

Планы не статичны: каждый описан как функция времени, поэтому машина
въезжает в кадр, монеты улетают в неё, кучка растёт по монете, а фигура
слева подтягивает руку к позе фигуры справа — то самое копирование, о
котором реплика. Кадры анимации идут прямо в ffmpeg, без тысячи PNG на
диске.

```bash
python3 series/ep04/draw_frames.py               # раскадровка + анимация планов
python3 series/ep04/draw_frames.py --stills-only # только раскадровка, быстро
python3 series/assemble.py series/ep04/manifest.json
```

Нужны `ffmpeg` и `rsvg-convert` (`apt install ffmpeg librsvg2-bin`).

## Свои материалы

Если кадры и текст уже сделаны где-то ещё, серия заводится с них, а не
рисуется заново:

```bash
python3 series/ingest.py --episode 4 \
    --frames ~/mm/ep04 --vo ~/mm/ep04/vo.txt --title "..."
python3 series/assemble.py series/ep04/manifest.json
```

Кадры берутся в естественном порядке имён (`frame2` раньше `frame10`) и
раскладываются по планам. Число планов задаёт файл реплик, а не папка: если
картинок пока меньше, недостающие планы остаются слейтами, сборка
продолжает работать, и дорисованные кадры просто докладываются в
`build/frames/` под именем плана.

## Сборка

`assemble.py` берёт по каждому плану лучшее, что есть: готовый клип →
кадр с медленным наездом → слейт с номером. Длительность плана берётся из
его озвучки, если она сгенерирована, иначе из манифеста. Пока озвучки нет,
реплики вжигаются субтитрами — иначе немой ролик нечитаем; с появлением
озвучки они отключаются сами (или флагом `--no-captions`).

Звук нормализуется до −14 LUFS — норма платформ, иначе они пережмут его
по-своему.

## Что мешает довести звук

Коннектор ElevenLabs авторизован неполно:

- `speech` — работает, реплики генерируются;
- `flows` — 403, поэтому забрать готовые файлы из сессии нельзя, они
  остаются на канвасе: https://elevenlabs.io/app/flows/SIGSPX6Jm6EZFrEUJOW9
- `image_video_generation` — 403, генерация картинок недоступна (на кадры
  это не повлияло, они рисуются кодом).

Когда файлы озвучки появятся, их надо разложить в `ep04/build/audio/` под
именами планов (`mm_ep04_01_a_car_goes_past.mp3` и так далее) и перезапустить
`assemble.py` — тайминг подстроится под реальную длину реплик сам.
