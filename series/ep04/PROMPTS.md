# Серия 4 — промпты кадров

34 сцен. Каждый промпт самодостаточный: стиль и описание персонажей
уже внутри, вставлять можно по одному в любой генератор — ничего добавлять не
нужно.

Готовый кадр сохранять **строго под именем плана** в
`series/ep04/build/frames/`, расширение любое из png/jpg/webp. Сборщик
находит кадры по имени, поэтому порядок и тайминг проставятся сами:

```bash
python3 series/assemble.py series/ep04/manifest.json
```

Планы, для которых кадра ещё нет, останутся заглушками — сборка не сломается,
можно докладывать по одному.

Соотношение сторон везде 16:9.
