# tiktok-tg-studio

Генерация коротких вертикальных роликов и кросспостинг: превью с аппрувом в
Telegram-канал → автопубликация в TikTok по расписанию.

## Как это работает

```
/new <промпт>  →  Higgsfield text→video  →  превью в TG-канал (кнопки ✅/🗑)
                                                     ↓ approved
                                     cron-слоты  →  TikTok publish
```

Состояния ролика в очереди: `new → generating → awaiting_approval → approved →
publishing → published`; при ошибке — `failed`, при отказе — `rejected`.
Публикация в TikTok при сбое возвращает ролик в `approved`, так что следующий
тик расписания попробует снова.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # заполнить токены
python -m app.main
```

Бот должен быть админом канала `TG_CHANNEL_ID` (право постить и редактировать
свои сообщения). Кнопки аппрува слушаются только от `TG_ADMIN_IDS`.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/new <промпт>` | генерит ролик и присылает превью на аппрув |
| `/caption <id> <текст>` | меняет подпись перед публикацией |
| `/queue` | сводка по статусам |
| `/publish` | публикует ближайшую партию, не дожидаясь слота |
| `/accounts` | список подключённых TikTok-аккаунтов |

## Настройки

Все — через `.env`, см. `.env.example`. Ключевое:

- `PUBLISH_CRON` — слоты публикации, **в UTC** (по умолчанию 09:00/15:00/20:00).
- `PUBLISH_BATCH` — сколько роликов выпускать за тик.
- `AUTO_APPROVE=true` — публиковать без ручного аппрува (превью в канал всё
  равно уходит, но уже без кнопок).
- `TIKTOK_ACCOUNT_ID` — взять из `/accounts`. Пока не задан, одобренные ролики
  копятся в очереди, а в канал падает предупреждение.

## Подключение TikTok-аккаунта

OAuth-привязка делается на стороне Higgsfield (`tiktok_connect`), после чего
аккаунт виден в `/accounts`. Токен живёт ограниченно — если публикация начнёт
отдавать ошибку авторизации, аккаунт надо переподключить.

## Про эндпойнты Higgsfield

REST-пути собраны константами в начале `app/providers/higgsfield.py`
(`EP_GENERATE_VIDEO`, `EP_TIKTOK_PUBLISH` и т.д.), а разбор ответа устойчив к
нескольким вариантам формы (`video_url` / `url` / `results[]`). Если в аккаунте
включена другая версия API, правится одним местом. Перед первым боевым запуском
стоит прогнать `/accounts` — это самый дешёвый способ проверить, что ключ и
базовый URL верные.
