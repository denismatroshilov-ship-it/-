# Голый берег

Выживание от первого лица под iPhone 12: остров, топор, костёр и ночь, в
которую к тебе приходят. Работает офлайн целиком — ни одного запроса в сеть,
ни одной внешней библиотеки, ни одного файла ассетов.

Это **не клон Rust и не порт Rust Mobile**. Точную копию Rust сделать нельзя:
это игра на движке Unity, десятки гигабайт моделей, звука и текстур плюс
серверная часть — и её модели, текстуры, интерфейс и название чужие. Здесь взят
жанр — цикл «собери → скрафти → построй → переживи ночь» — и сделан с нуля
своей графикой и своим кодом.

## Что внутри

- Процедурный остров 256×256 м: рельеф, пляж, лес, скалы, руины с антенной как
  единственным ориентиром. Карта выводится из seed'а, файлов карты нет.
- Ресурсы: сосна и дуб (дерево), камни (камень), руда (металл через костёр),
  конопля (ткань), ягоды, бочки и ящики у руин (лом).
- Крафт без верстака: каменные топор и кирка, копьё, лук со стрелами, факел,
  бинт, план стройки; металлические инструменты — вдвое быстрее.
- Стройка по сетке 3 м: фундамент, стена, дверной проём, дверь, потолок;
  улучшение дерева до камня. Дверь открывается и закрывается.
- Выживание: здоровье, голод, жажда, холод ночью. Пресная вода только в
  родниках — море не пить.
- Живность: олени (мясо и ткань) и волки, которые ночью охотятся на тебя.
- Ночью от антенны идут мародёры: с каждым днём их больше, и стену они
  проламывают.
- Смерть: половина припасов остаётся мешком на месте гибели, возрождение — на
  спальнике или снова на берегу.
- Сохранение автоматическое (localStorage) каждые 20 секунд и при выходе.

## Как запустить на телефоне

1. Открыть страницу игры в Safari.
2. Поделиться → «На экран „Домой“».

После этого игра запускается как приложение и работает без интернета: service
worker кладёт в кэш все пять файлов, а больше ей ничего не нужно.

Локально с компьютера:

```bash
cd bereg && python3 -m http.server 8000
# телефон в той же сети: http://<ip-компьютера>:8000
```

## Управление

| Что | Как |
| --- | --- |
| Идти | левая половина экрана, палец до упора — бег |
| Осмотреться | правая половина экрана |
| Бить, рубить, копать | кнопка УДАР (держать — бьёт сам) |
| Пить, есть, дверь, дрова, мешок | кнопка ВЗЯТЬ |
| Инструменты | нижний ряд слотов |
| Стройка | слот с планом → панель над слотами |

На компьютере: WASD, мышь — обзор и удар, E — взять, C — крафт, 1–6 — слоты.

## Из чего собрано

| Файл | Что внутри |
| --- | --- |
| `gl.js` | микродвижок WebGL2: шейдеры, инстансинг, небо, туман, точечный свет |
| `world.js` | генерация острова, ресурсы, коллизии, постройки, сериализация |
| `game.js` | игрок, физика, сбор, крафт, стройка, ИИ, ночные волны, интерфейс |
| `styles.css` | HUD и экраны под палец, с учётом «чёлки» и home-индикатора |
| `sw.js` | оффлайн-кэш |

Вся геометрия строится кодом из коробок, цилиндров и сфер с цветом в вершинах —
текстур нет вообще, поэтому игра весит десятки килобайт и грузится мгновенно.

Баланс собран в начале `game.js` одним блоком: цены крафта, урон инструментов,
скорость голода и жажды, цена промаха. Менять игру нужно там.

```js
const DRAIN = { hunger: 100 / 720, thirst: 100 / 540 };  // за сколько секунд до нуля
const TOOLS = { axe: { dmg: { tree: 26, ... }, rate: 0.5 }, ... };
```

## Чего в игре нет

Осознанно не сделано, чтобы игра осталась играбельной на телефоне и без сети:
мультиплеер и рейды других игроков, огнестрел и патроны, электричество,
многоэтажные постройки (пока только первый уровень), вертолёты и радтауны,
приручение, крупные монументы. Всё это — следующий слой, не первый.
